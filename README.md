# 情侣事件记录网站

一个本地可运行的 Flask 小网站，用来记录情侣之间的重要事件、日常回忆和照片。

## 运行方式

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

打开浏览器访问：

```text
http://127.0.0.1:5000
```

数据库会自动创建在 `instance/couple.db`，上传图片会保存在 `static/uploads/`。
